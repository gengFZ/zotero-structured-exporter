Zotero 结构化导出器
====================

作用
----
把 Zotero 收藏夹整理成普通文件夹，便于浏览、打包和分享：

收藏夹\
  作者-年份-标题\
    PDF原文\
    笔记\阅读笔记.html
    笔记\images\
    文献信息.html

使用方法
--------
1. 下载本项目中的全部文件，并放在同一个文件夹内。
2. 双击“运行Zotero导出器.cmd”。脚本可自动启动 Zotero；若连接失败，请在
   Zotero“设置 → 高级 → API”中启用本地 API。
3. 输入收藏夹名称或屏幕上显示的 8 位收藏夹键。
4. 默认导出到桌面上的“Zotero结构化导出”。如果该目录已存在，脚本会新建
   带日期时间的目录，不会直接覆盖原导出内容。

保留 PDF 批注
------------
Zotero 本地 API 只能提供原始 PDF，不能直接把数据库中的高亮和批注写回 PDF。
如需保留批注，请先在 Zotero 中选择文献，使用“文件 → 导出 PDF”，勾选包含
批注并导出到一个临时文件夹；运行本工具时输入该文件夹路径。工具会按原 PDF
文件名匹配并优先复制带批注版本。同名 PDF 较多时请在分享前人工核对。

注意
----
- 工具只访问本机 127.0.0.1:23119，不会上传 Zotero 数据。
- 导出结果可能包含有版权的 PDF、个人笔记和附件，公开分享前请自行检查授权
  和隐私内容。
- 网页快照可能引用外部资源；离线打开时部分样式或图片可能无法显示。
- 需要 Windows PowerShell 5.1 或更高版本，以及 Windows 自带的 curl.exe。

更多说明见 README.md。
